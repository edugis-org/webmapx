CDN

Use on any page

One script tag. No npm, no build tools. Works in any HTML file served from a static host.

<script type="module">
import { WebMapX } from
  'https://cdn.jsdelivr.net/npm/
   @edugis-org/webmapx@latest/
   dist-lib/webmapx.js';
WebMapX.mount('#map',
  { config: './mymap.json' });
</script>

npm

Use in a Vite / webpack project

Install from npm, import in your app. Tree-shaken, typed, works with any modern bundler. Add the map engine you want as a peer dependency.

npm install @edugis-org/webmapx
# plus one engine:
npm install maplibre-gl  # MapLibre
npm install ol           # OpenLayers
npm install leaflet      # Leaflet
npm install cesium       # Cesium
import { WebMapX } from
  '@edugis-org/webmapx';
WebMapX.mount('#map',
  { config: './mymap.json' });

Dev / contributor

Run locally

Clone the repo, run the dev server, modify tools and engines with hot reload.

git clone https://github.com/
  edugis-org/webmapx.git
cd webmapx
npm install && npm run dev
Dev guide → GitHub →
Plugin

Extend with custom tools

Build your own tools as ES modules. Load them from any CDN — no fork needed.

config: {
  plugins: [
    'https://cdn.example.com/
     my-tool.js'
  ]
}
