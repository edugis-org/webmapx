Click a shape with the info tool to read what was computed for it — the hours of daylight on a day-length line, the EPSG code of a UTM zone, the distance along a great circle. That is where these layers keep their answer; the shape only says where it applies.

Styling

WebMapX does not style these layers. A generator returns GeoJSON carrying the attributes listed in the reference; every colour, width and rule after that is written by whoever writes the config.
