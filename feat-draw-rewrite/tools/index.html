Tools

Opened from a toolbar, and answered in a panel. A tool is something you go to when you have a question — measure this, tell me about that, draw here — and close again when you are done. Each one is a tools entry naming its type, plus an item in a toolbar.

Map controls

Drawn on the map itself rather than in a panel. A control is furniture: a scale bar, a coordinate readout, a north arrow — it takes a position such as bottom-left instead of a toolbar entry, and it is simply present rather than opened. The toolbar that holds the tools is positioned on the map the same way, though it is a container rather than a tool in its own right.

Engine label
activeAdapter		Shows which map engine is being used.
Attribution
attribution		The credit your data requires, kept legible.
Coordinates
coordinates		Shows pointer coordinates in the chosen format.
Fullscreen
fullscreen		Fills the screen with the map.
Inset map
insetMap		Shows where the main map is.
Navigation
navigation		Provides zoom buttons and a compass.
Scale bar
scale		Shows the current map scale.
Spinner
spinner		Shows when the map is busy.
Zoom level
zoomLevel		Shows and sets the current zoom level.

Calculated layers

Data worked out in the browser rather than fetched — where night falls, where the moon stands, what a projection does to a circle, where the coastlines were 200 million years ago. A source names one with an internalfunc:// url instead of an address, which is also how a reader of a config can tell at a glance that nothing is downloaded.
