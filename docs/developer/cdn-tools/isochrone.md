# Tool: isochrone

Draw reachability areas (isochrones) from a clicked point — showing how far you can travel within a given time by foot, bike, or car. Uses a configurable routing service.

**Tool id:** `isochrone`  
**Load:** lazy

## Example

```js
tools: ['isochrone']
```

Requires a routing service API key in the app config. See the config JSON for your deployment.
