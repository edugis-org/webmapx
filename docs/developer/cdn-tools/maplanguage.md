# Tool: maplanguage

Switch the label language on OSM vector tile layers. Picks from available language columns in the tile data.

**Tool id:** `maplanguage` (alias: `language-osmvector`)  
**Load:** lazy

## Example

```js
tools: ['maplanguage']
```

Only effective with OSM vector tile sources that include multilingual name fields.
